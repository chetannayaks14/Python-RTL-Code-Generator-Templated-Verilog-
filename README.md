# Python-RTL-Code-Generator-Templated-Verilog-

Python RTL Code Generator – Templated Verilog Python, Jinja2, JSON/YAML, Verilog, Git
• Built a Python tool that reads a structured JSON/YAML model and generates synthesisable Verilog via Jinja2
templates; validated generated RTL against hand-written reference modules in simulation to confirm functional
equivalence.
• Designed the generator to produce multiple configurations from a single model without code duplication, and
version-controlled every output in Git to keep generated and reference designs traceable.
